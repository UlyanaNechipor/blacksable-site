# Скрипты сайта Black Sable (blacksable.ru)

Здесь лежит весь код, который раньше стоял блоками в подвале (футере) Тильды.
Сайт загружает один файл — `blacksable.js`. Правка в этом репозитории попадает на сайт
без переопубликации страниц в Тильде.

## Что где

| Файл | Что делает |
|---|---|
| `src/01-price.js` | цена в заголовке карточки |
| `src/02-card-logic.js` | кнопка «Добавить в заказ» / «Оформить предзаказ», скрытие лишних характеристик |
| `src/03-store-helpers.js` | переименование кнопок, кликабельные размеры, скрытие «нет в наличии» в каталоге |
| `src/04-colors.js` | строка цветов, наличие по цвету и размеру, верная модификация в корзине; **список товаров с цветами — в начале файла (`GROUPS`)** |
| `src/05-typograph.js` | висячие предлоги и союзы |
| `src/06-partner-stock.js` | наличие у магазинов-партнёров в штуках (данные — `data/partners.json`) |
| `src/07-catalog-colors.js` | в каталоге отдельная карточка для каждого цвета (фото — `data/catalog-colors.json`) |
| `blacksable.js` | собранный файл, который загружает сайт (собирается командой `python3 tools/build.py`) |

## Что остаётся в самой Тильде

- **HEAD сайта:** «Ускоритель» (скрытие кнопки до расчёта наличия, свежая версия страницы).
- **Подвал:** строка загрузки этого файла, блок согласия в форме подписки и шрифты Zero-блоков.
